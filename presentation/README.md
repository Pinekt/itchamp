# Презентация КТК ЭЛОУ-АВТ

13 слайдов — предел, заданный кейсом.

| Файл | Что это |
|---|---|
| `КТК-ЭЛОУ-АВТ.pptx` | презентация |
| `КТК-ЭЛОУ-АВТ.pdf` | она же в PDF |
| `build.js` | генератор: из него собираются оба файла |
| `img/` | скриншоты работающего стенда |

## Важно: макет организаторов

Кейс требует презентацию **по макету организаторов**. Макет лежит в
`materials/` у капитана и в репозиторий намеренно не попадает. Вёрстка здесь
своя — содержание готово, но перед сдачей его нужно перенести в официальный
шаблон или наложить шаблон на эти слайды.

## Что нужно дописать

- **Фамилии** участников на титульном слайде — сейчас только имена.
- **Экономическое обоснование** (слайд 13) — стоимость внедрения и срок
  окупаемости. Блок на слайде есть, цифры за аналитиком: выдумывать их
  нельзя, их спросят на защите.

## Сборка

Скриншоты в `img/` сняты на работающем стенде, а не нарисованы. Пересобрать
после правки `build.js`:

```bash
npm install pptxgenjs
node build.js
soffice --headless --convert-to pdf КТК-ЭЛОУ-АВТ.pptx
```

Пути к картинкам в `build.js` заданы константой `IMG` — поправьте её под свою
машину перед сборкой.

## Как слайды закрывают критерии

| Слайд | Критерий |
|---|---|
| 2 «Задача и результат» | демонстрация, конкурентоспособность |
| 3 «Рабочее место», 4 «Цифровой двойник» | техническая реализация (вес 0,25) |
| 5, 6 «ИИ» | использование ИИ |
| 7 «Разбор тренировки» | техническая реализация, оценка персонала |
| 8 «Архитектура» | архитектура |
| 9 «Информационная безопасность» | ИБ |
| 10 «Инфраструктура», 11 «Производительность» | инфраструктура, техническая реализация |
| 12 «Импортонезависимость» | требования кейса |
| 13 «Внедрение» | конкурентоспособность и внедрение |

Заметки докладчика есть на каждом слайде — в них то, что стоит сказать
голосом, а не выносить в текст.
