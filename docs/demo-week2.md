# Демонстрация команде — итоги недели 2

Цель показа: убедить команду, что каркас работает и каждый может начать
подключать свою часть. Занимает ~10 минут.

## 0. Подготовка (1 команда)

```bash
docker compose up --build
```

Открыть: тренажёр **http://localhost:8000**, pgAdmin **http://localhost:5050**
(admin@ktk.local / admin; сервер `ktk-db`, база `ktk_eloyavt`, ktk / ktk).

## 1. Что показать в интерфейсе (5 минут)

1. **Выбор сценария** — в списке три сценария, они пришли из БД, а не из кода.
   Значит инструктор сможет добавлять свои.
2. Выбрать «Рост давления в колонне» → **Загрузить** → **Пуск процесса**.
3. Обратить внимание: параметры идут **в реальном времени** (это прямо требование
   критерия «демонстрация» — не скриншоты).
4. На 10-й секунде **срабатывает отказ** — давление растёт само, по расписанию сценария.
5. Не реагировать специально → загорается авария, **ИИ-ассистент** пишет класс ошибки
   и рекомендацию, ползёт индикатор риска.
6. **Журнал действий** пишет каждое действие с временем реакции в миллисекундах.
7. Нажать **Завершить** → приходит **оценка квалификации**: баллы и вердикт
   «сдал / не сдал».

## 2. Что показать в базе (3 минуты)

В pgAdmin выполнить:

```sql
SELECT s.scenario_code, s.operator, a.total_score, a.verdict, a.errors_count
FROM training_sessions s LEFT JOIN assessments a ON a.session_id = s.id
ORDER BY s.started_at DESC;

SELECT t, error_class, location, severity, risk_score FROM detected_errors ORDER BY t;
SELECT order_no, expected_action, description, critical FROM scenario_steps LIMIT 8;
```

Мысль для команды: **9 таблиц спроектированы под критерии оценки** —
эталонные шаги нужны ИИ для сравнения, аудит и роли закрывают ИБ,
assessments закрывает «оценку квалификации персонала».

## Полезные API для проверки

- `GET /api/scenarios` — сценарии из БД
- `GET /api/scenarios/pump_trip/reference` — эталонные шаги
- `GET /api/sessions` — список тренировок
- `GET /api/sessions/{id}/journal` — журнал действий
- `GET /api/sessions/{id}/errors` — ошибки, найденные ИИ
- `GET /api/sessions/{id}/assessment` — итоговая оценка
